# Подключение AI Cascade Router к Cline

## Настройка

1. Откройте Cline в VS Code
2. Перейдите в **Settings** → **API Provider**
3. Выберите **OpenAI Compatible**
4. Заполните поля:
   - **API Base URL:** `http://localhost:8000/v1`
   - **API Key:** `cascade-router` (любое значение)
   - **Model:** `cascade-router`

## Проверка

Отправьте любой запрос в Cline. В dashboard (http://localhost:8000) вы увидите:
- Запрос обработан локально или в облако
- Сэкономленные токены
- Стоимость

## Автоматическая маршрутизация

Cline не знает о маршрутизации — он просто отправляет запросы на `http://localhost:8000/v1`.
Роутер сам решает, куда направить запрос:
- Простые вопросы → локальная модель (бесплатно)
- Сложный код/анализ → облако (платно, но качественно)
